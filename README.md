# sprint5: Statistical data analysis

Sprint Project

In this sprint, the performance of two prepaid plans will be analyzed to determine which generates the most revenue, helping to optimize advertising strategies.

The project is divided into four key stages:

Stage 1: Data Exploration. Load and examine the dataset, ensuring the data types are correct and identifying any issues.
Stage 2: Data Preparation. Clean the data, correct errors, and calculate monthly usage and revenue for each user.
Stage 3: Data Analysis and Visualization. Analyze user behavior using statistical metrics and visualize the results to understand usage patterns.
Stage 4: Hypothesis Testing. Test hypotheses to compare revenue between the two plans and across regions, using appropriate statistical methods.
